读完这本书，你能回答的七个问题

这本书只讲一个东西：光模块，AI 数据中心里站在每一个"电"与"光"交界处的翻译官。第一部分讲它是什么、为什么变；第二部分逐个环节讲谁在做、凭什么、现在过得怎么样；第三部分讲还没定的事。

面对一个陌生行业，难的不是找不到资料，而是资料太多，不知道哪些重要、它们之间是什么关系。这本书不罗列知识点，只回答七个问题。读完之后，你应该能用自己的话把这七句说出来。七句里的词（DSP、硅光、CPO）现在看不懂没关系，每一章会逐个定义，这里只是先把地图摊开：

问题一
它在哪
成千上万颗 GPU 靠交换机连成一张网。光模块插在交换机和网卡的每一个对外口上：机柜里面用铜，机柜之间用光。
问题二
它干什么，为什么省不掉
铜线上的高速电信号因为趋肤效应和介质损耗，跑远了就分不清 0 和 1；光纤的损耗不随速率恶化。跨机柜必须换成光，所以每个交界处都要一个翻译官。
问题三
里面有什么，哪块最难
一条发射链，一条接收链。最贵最缺的零件是磷化铟激光器，最耗电的是 DSP，良率靠微米级的耦合封装。
问题四
它为什么在变
AI 对带宽的需求增速远快于电信号的进步速度，所以光电转换点被迫一步步靠近芯片。这一句能解释过去二十年，也能推出未来几年。
问题五
钱怎么流，定价权在哪
云厂商的资本开支经 GPU 和交换机流到模块厂，再流到上游芯片。缺货时能涨价的是最上游的激光器和 DSP，以及最下游的 GPU；中间的模块厂量最大、利润最薄。
问题六
每个环节站着谁
十个环节，每个环节一页：做什么、为什么难、谁在做、代表产品、现状、路线影响、看哪个数。

硅光占比升多快、CPO 何时量产、铜还能守几米。每一个都落到一个能观察的物理量上。

先打掉一个错误直觉

"买 GPU 就是买算力，一颗 GPU 算力强集群就强。"错在漏了两件事：一颗 GPU 装不下今天的模型，也算不完今天的训练；把几万颗连起来之后，"连得快不快"就和"算得快不快"一样重要。

为什么一颗 GPU 不够：容量和时间

先看容量。训练一个大模型，要把模型的全部参数、每个参数的梯度和优化器状态都放在显存里。以混合精度加 Adam 优化器为例，每个参数大约要占 16 字节1。一个几千亿参数的模型，光这些"模型状态"就是几个 TB，而一颗 GPU 的显存是几十到几百 GB。所以模型必须被切开，分到很多颗 GPU 上，这叫模型并行。

再看时间。训练需要的总计算量等于"参数量乘数据量乘一个常数"，是天文数字；一颗 GPU 算完要几十年，几千颗一起算才能压到几个月。Meta 训练 Llama 3 405B 用了 16,000 颗 H1002。这叫数据并行：把训练数据切成很多份，每颗 GPU 拿一份算。

为什么它们必须不停地说话：同步

数据并行有个硬约束：每颗 GPU 用自己那份数据算出来的梯度，只是"部分答案"。要更新模型，必须把所有 GPU 的梯度求和平均，再把结果发回每一颗。这个动作叫全归约（all-reduce），每训练一步做一次；一步的通信量和参数量同一个量级1。模型并行更狠：一层算完的中间结果要马上传给持有下一层的 GPU，一步之内要传很多次。

所以 GPU 之间不是偶尔传个文件，而是每一步都要交换和参数量相当的数据。网络慢了，GPU 就在等。业内衡量这件事的指标叫"通信时间占比"：网络越慢、集群越大，GPU 空转的比例越高，算力就浪费了。这就是第 1 章标题的答案：连在一起是训练的数学结构决定的，不是工程偏好。

这几万颗 GPU 怎么装：四层

第一层
服务器（托盘）
一块板子上装 2 到 8 颗 GPU，是最小的单元。
第二层
机柜
一个柜子装十几台服务器。英伟达把一整柜 72 颗 GPU 当一台机器卖，柜里的 GPU 之间用铜线直连。
第三层
交换机
把机柜和机柜连成一张网的设备。机柜之间隔几十到几百米。
第四层
集群
几百上千个机柜通过两三层交换机连成一台"超级计算机"。

话筒和总机：网卡与交换机

一颗 GPU 要把梯度发给别的 GPU，先要有一个对外的口，这就是网卡（NIC，Network Interface Card，网络接口卡）。网卡把 GPU 显存里的数据打包成网络报文发出去，也接收别人发来的报文。Rubin 一代每颗 GPU 配的网卡带宽是 1.6 Tb/s，也就是两个 800G 口3。

几万个口不能两两拉线，中间要有交换机（switch）：它读每个报文的目的地址，把报文转到正确的出口。机柜顶上先有一级交换机，它们之间再由更大的交换机连起来，两到三层就能把十万张卡连成一张网。论坛上阿里云的十万卡设计用的就是两层结构，讲者的理由是三层会多一层核心交换机，交换机、光纤、光模块的数量都会大增，还多两跳时延4。

光模块在哪

机柜里面 GPU 之间距离一两米，用铜线直连。一出机柜，距离变成几十到几百米，铜线就撑不住了（为什么撑不住，第 2 章讲）。这时每一根连线的两头各要插一只光模块：这头把电变成光送进光纤，那头把光变回电交给交换机。交换机之间的连线也一样，每一跳、每一头都要一只。

本章核心

GPU 必须连在一起，是因为模型装不下一颗卡、算不完一颗卡，而且每一步都要同步梯度。光模块不是单独存在的东西，它只在"GPU 互联"里有价值：GPU 越多、集群越大，交界处越多，翻译官就要得越多。

和翻译官对照

几万个人做同一份作业，每算一步都要对一次答案；谁慢一步，所有人等它。网卡是每个人的话筒，交换机是总机，光模块是话筒和听筒旁边的翻译官。

投资视角

这就是为什么英伟达的财报会牵动中际旭创、新易盛、Coherent 的股价：它们卖的是翻译官，翻译官的数量跟着 GPU 和交换机的口数走。每颗 GPU 大约配多少只，为什么这个比例不是常数，见本章参考层和第 10 章。

再深一层：物理细节与推导（读不懂可跳过，不影响主线）

梯度同步的通信量。 全归约把 N 颗 GPU 上各自的梯度向量求和后广播回去，常用的环形算法里每颗 GPU 要发送和接收约 2×(N−1)/N 倍参数量的数据，N 大时接近 2 倍参数量。参数以 16 位浮点存储时，一个 4,000 亿参数的模型每步每卡要传约 1.6 TB 量级的数据；实际系统用分层归约和通信计算重叠来压缩这个时间，但量级不变。这也是为什么柜内 NVLink 要做到每颗 GPU 双向 3.6 TB/s，而柜外网卡只有 1.6 Tb/s，两者差约 18 倍3，所以能放柜内的通信尽量放柜内。

16 字节从哪来。 混合精度训练里，每个参数要存 fp16 权重（2 字节）、fp16 梯度（2 字节）、fp32 主权重（4 字节）、Adam 的两个动量（各 4 字节），合计 16 字节。这是 ZeRO 论文的口径，只算模型状态，不算激活值和缓冲区1。

为什么是两层还是三层。 交换机的口数有限，一台 128 口的交换机直连 128 张卡；要连十万张卡，必须让交换机再连交换机。层数越多，每条路径经过的光模块越多，时延也越高。英伟达的多平面设计把每颗 GPU 的带宽拆成多个独立平面，用两层网络连了十几万端点5，所以层数不随规模线性增加。

为什么一颗 GPU 不够？两个理由。
装不下：模型状态每参数约 16 字节，几千亿参数要几个 TB；算不完：总计算量要几千颗 GPU 并行才能在几个月内完成。
数据并行为什么必须每步通信？
每颗 GPU 算出的梯度只是部分答案，要把所有卡的梯度求和平均再发回去，一步一次，通信量与参数量同量级。
光模块插在哪？机柜里有没有？
插在网卡和交换机的每个对外口上，一根光纤两头各一只。机柜内 GPU 之间是铜线，没有光模块。

先打掉一个错误直觉

"光纤的优势是更快。"光在光纤里的速度约为真空光速的三分之二，电信号在铜线里也差不多。光纤真正的优势是损耗不随速率恶化，所以跑远了还能分清 0 和 1。

电信号为什么跑不远：两种损耗

数字信号是一串方波：高电平是 1，低电平是 0。一个方波不是单一频率，它由一个基频和许多高次谐波叠加而成，边沿越陡、速率越高，包含的高频分量越多。铜线对不同频率的损耗不一样，高频损耗更大，这是问题的根源。

第一种损耗叫趋肤效应（skin effect）。交变电流在导线里会产生变化的磁场，这个磁场在导线内部感应出反向的涡流，抵消中心的电流、加强表面的电流。频率越高，这种抵消越强，电流实际只在导线表面很薄的一层里流动，有效截面积缩小，电阻上升。趋肤深度与频率的平方根成反比，所以电阻随频率的平方根上升1。第二种叫介质损耗：电路板和电缆的绝缘材料在高频电场里反复极化，把一部分电能变成热，这一项随频率线性上升。两者叠加，损耗按分贝计大约和"频率的平方根到一次方"乘"距离"成正比。

后果是：速率翻倍，同样一段铜线上的损耗大约增加一半到一倍，能传清楚的距离就大致砍半。论坛上 Marvell 和立讯给的口径一致：每路信号 100G 时无源铜线约 2 米，200G 时约 1 米，400G 时更短23。"每路信号"在第 3 章会叫"每车道"。

"糊"是什么：码间干扰

高频分量衰减得比低频多，方波的边沿就被磨圆，一个比特的能量拖进了下一个比特的时间窗，相邻的 0 和 1 互相重叠，这叫码间干扰（ISI，Inter-Symbol Interference）。接收端看到的不再是清楚的高低电平，而是一团混在一起的波形，分不清哪个是 0、哪个是 1。工程上用"眼图"来看这件事：把很多比特叠在一起画，中间空的那块"眼睛"越大越好；码间干扰让眼睛闭上。

用大白话说：隔着一堵厚墙喊话，慢慢说还能听清，越说越快就越听不清，因为墙把尖锐的辅音吃掉了，只剩下拖长的元音。这就是第 4 章 DSP 存在的理由：它要在接收端把被磨圆的边沿算回来。

光为什么能

光纤是一根玻璃丝，芯（纤芯）的折射率比外层（包层）略高。光从芯里以小角度射向边界时，因为折射率差会发生全反射，一点都漏不出去，于是被困在芯里一路向前。光的损耗来自玻璃本身的散射和吸收，通信用的石英光纤在 1,310 纳米和 1,550 纳米两个窗口损耗最低，每公里只有零点几分贝4。

关键在于：光纤的损耗由波长决定，不由数据速率决定。把速率从 100G 提到 200G，铜线的损耗会跟着涨，光纤的损耗几乎不变。光信号也不受周围电磁环境的干扰，不会像并排的铜线那样互相串扰。所以同样一段话，用光传，跑几十米、几百米甚至几公里，到了对面还是清楚的。

铜线
损耗随频率的平方根到一次方上升
速率翻倍，可达距离大约砍半
要传清楚就得加均衡电路，更耗电
光纤
损耗由波长决定，每公里零点几分贝
速率提高，损耗几乎不变
不受电磁干扰，无串扰
光纤不是零损耗，也不是更快。它的优势是损耗与速率解耦。

一根光纤，两只翻译官

芯片不会发光，也听不懂光。GPU、网卡、交换机里的一切都是电信号。要用光纤，就必须在每一根光纤的两头各放一个翻译官：这头把电变成光，那头把光变回电。这个动作叫光电转换，做这个动作的盒子就是光模块。

所以光和铜的成本结构不同。铜线本身便宜，贵在距离和速率：越远越贵，越快越贵，到一定程度就传不了。光纤本身也便宜，几乎不随距离变；贵的是两头的翻译官，每一个端口都要买一只。把两条成本曲线画在一起有一个交叉点：短于它铜便宜，长于它光便宜。今天这个交叉点在一两米附近，所以机柜里用铜，机柜外用光。

本章核心

铜线的损耗随频率上升（趋肤效应加介质损耗），速率翻倍可达距离砍半，高频分量衰减导致码间干扰；光纤的损耗由波长决定，与速率解耦。芯片只会说电，所以每根光纤两头各要一只光模块。铜按距离付费，光按端口付费。

和翻译官对照

说话的人（GPU）越说越快，隔着墙能听清的距离越来越短；换成光纤就像换成一根隔音的传声管，说多快都不糊。但传声管两头必须各站一个翻译官。

投资视角

"光进铜退"不是口号，是那个交叉点的位置。GPU 说话每快一代，交叉点就往左挪一格。但铜的厂商也在想办法把交叉点往右拽，第 17 章和第 20 章会看到他们怎么做。

再深一层：物理细节与推导（读不懂可跳过，不影响主线）

趋肤深度。 δ = √(ρ / (π f μ))，ρ 是电阻率，f 是频率，μ 是磁导率。铜在 1 GHz 时趋肤深度约 2 微米，在 50 GHz 时约 0.3 微米。导线截面里只有表面这一薄层在导电，交流电阻按 √f 上升。

损耗的数量级。 每车道 224G 的信号（PAM4 调制下奈奎斯特频率约 56 GHz），1.5 米无源铜缆的插入损耗约 40 dB，即功率只剩万分之一、电压幅度只剩百分之一5。光纤在 1,310 纳米窗口每公里约 0.3 dB，1,550 纳米约 0.2 dB4，一公里的损耗比 1.5 米铜缆小两个数量级。

全反射的条件。 光从折射率高的介质射向折射率低的介质，入射角大于临界角时全部反射。单模光纤纤芯直径约 9 微米，只允许一个传播模式，所以没有多模光纤里不同路径走不同时间造成的脉冲展宽；这也是为什么长距离用单模。

为什么铜还没死。 一米以内的距离上，铜线的功耗、成本和可靠性仍然碾压光：不需要激光器、不需要光电转换、坏了的概率低得多。NVL72 一个机柜里用了五千多根 NVLink 铜缆连 72 颗 GPU6。铜的问题从来不是"不行"，而是它的经济半径每代砍一半。

先打掉一个错误直觉

"1.6T 比 800G 难，是因为通道翻倍了吧？"不是。两代的车道数可以一样多，难在每条车道要跑两倍快。为什么不干脆多加几条车道，是这一章真正要回答的问题。

一只模块里不止一条路

一只光模块里并排着 4 条或 8 条车道（lane）：每条车道是一路独立的电信号，各自变成一路光。总速率等于车道数乘每车道速率。光迅科技蒋波在论坛上说得直白："速率等于带宽乘以通道数，不管是光口也好，电口也好，都要遵循这样的一个数学题。"1

代际怎么凑出来每条车道一句话状态（2026-09）
400G8 × 50G 或 4 × 100G50G / 100G上一代，云厂商还在大量用
800G8 × 100G，新一代也有 4 × 200G100G / 200G当前主力
1.6T8 × 200G200G正在放量
3.2T8 × 400G 或 16 × 200G200G / 400G展会上的样品，调制格式未收敛
从 800G 到 1.6T，主流做法车道数不变，每条车道快一倍。

为什么不能一直加通道

既然总速率等于车道数乘每车道速率，为什么行业不靠多加车道来提速？三个原因，从交换机那头说起。

第一，交换芯片的口数几乎不涨。 交换芯片对外的每一路高速信号都要占芯片边缘的一段长度和封装上的一组引脚，芯片边长和引脚数受制造工艺限制，一代芯片能放的高速口数大致固定。博通最新一代交换芯片提供两种配置：1,024 条 100G 车道，或 512 条 200G 车道，总带宽都是 102.4T2。要让一颗芯片的总带宽翻倍，只能让每条车道翻倍。芯片这头车道速率翻倍了，插在它口上的模块就必须跟上。

第二，车道多一倍，零件多一倍。 每条车道各要一颗激光器、一颗探测器、一根光纤、一套放大电路和一段封装对准。16 条车道的模块比 8 条的体积大、功耗高、光纤和连接器多一倍，交换机前面板的密度撑不住。

第三，良率是累积的。 立讯彭小伟的原话："光模块的制造，它的良率是累积的，你不是说你 90% 综合起来是 90%，它是取一个累积的概念。"3每条车道每道工序都有自己的良率，最终良率是它们的乘积。四道 90% 相乘只剩 66%，通道越多、工序越多，能出厂的合格品越少。

所以行业选的路是：车道数尽量不动，把每条车道做快。这就把难题推到了两个零件上：发光的零件要闪得更快，收光和整形的零件要分辨得更细。第 4、5、6 章讲这两个零件。

名字怎么读

把两块拼起来，产品名就能读了。1.6T DR8：总速率 1.6T，五百米级单模，8 条车道。800G SR8：总速率 800G，百米内多模，8 条车道。再看到 OSFP、QSFP-DD，那是外壳尺寸的规格名，决定插进什么笼位；1.6T 基本用 OSFP，因为散热更好4。

本章核心

总速率等于车道数乘每车道速率。不能一直加车道，因为交换芯片的口数几乎不涨、零件随车道数线性增加、良率随工序数累积下降。所以每一代的难点是每车道速率。距离等级决定光源和光纤。

和翻译官对照

翻译官小组里 8 个人并排翻译。要让整组翻得更快，不能再加人，因为门口（交换芯片的口）站不下、每个人都要配一套设备、人越多出错的概率越高。只能让每个人说得更快。

投资视角

再深一层：物理细节与推导（读不懂可跳过，不影响主线）

每车道怎么跑出两倍速。 早期信号只有高低两个电平，一次变化传 1 比特（NRZ）；现在主流用四个电平，一次变化传 2 比特（PAM4），同样的符号速率跑出两倍数据。代价是四个电平之间的间距只有原来的三分之一，更容易被噪声混淆，所以需要更强的 DSP 纠错和更高的信噪比。400G 每车道之后用 PAM4、PAM6 还是更高阶，行业还没收敛；蒋波的判断是 PAM8 对信噪比要求太高，目前不现实1。

符号速率与频率。 每车道 200G PAM4 的符号速率约 112 GBaud，信号的主要频率分量到约 56 GHz。这就是第 2 章损耗计算的输入。

"慢而宽"的另一条路。 论坛上新易盛提到 MicroLED 方案：单通道只有几 Gb/s，用几百条通道并行凑出 1.6T，优点是不需要 DSP、能效极低，缺点是通道排列数量太多5。它绕开了"每车道提速"这条主线，目前处于早期，第 14 章再提。

先打掉一个错误直觉

第一站：DSP 做的两件事

DSP（Digital Signal Processor，数字信号处理器；光模块里这一颗常叫 ODSP，O 是 optical）先用模数转换器把进来的模拟波形采样成数字，再做两件事。第一件叫均衡（equalization）：信道对高频分量衰减得多，DSP 就对高频分量补偿得多，相当于把第 2 章那堵墙的传递函数反过来算一遍，把磨圆的边沿重新竖起来。常用的算法是前馈均衡和判决反馈均衡，本质都是用前后几个符号的加权和来抵消码间干扰1。第二件叫重定时（retiming）：从信号里恢复出时钟，把每个符号重新对准节拍，消掉传输中积累的抖动。

这颗芯片为什么最难、最耗电，第 5 章和第 11 章展开。这里只记一点：每车道 224G 时，DSP 要在 55 GHz 以上的模拟带宽下工作，采样时钟的抖动要低于 100 飞秒1，所以要用 3 纳米这样的先进工艺做模拟混合信号设计，全球能做的团队屈指可数。

第二站：驱动器

DSP 输出的信号干净但微弱，推不动光器件。驱动器（driver）是一级高速放大电路，把信号放大到激光器或调制器需要的电压摆幅。不同的光器件要的摆幅不同：直接调制的激光器要电流摆幅，电吸收调制器要一两伏的电压摆幅，硅光的马赫曾德调制器（第 6 章讲）要更大的摆幅。所以驱动器和光器件是配对设计的，换一种光源就要换一种驱动器，这一点第 12 章会用到。

第三站：激光器为什么能发出"一种颜色"的光

普通灯泡发的光是各种波长的混合、各个方向乱射。通信要的光必须是单一波长、方向一致、能持续稳定输出，这是激光（laser）。它的原理有两步。第一步叫受激辐射：半导体材料里的电子被注入电流抬到高能级，当一个光子经过时，电子跳回低能级、放出一个和这个光子波长、相位、方向完全一样的新光子，一个变两个。第二步叫谐振腔：在发光材料两端放两面镜子，光子在两面镜子之间来回反射，每来回一次就被放大一次，只有波长正好能在腔里形成驻波的那一种颜色被反复放大，其余的被压掉。一面镜子留一点透光，放出去的就是激光2。

通信用的激光器是在半导体芯片上做出来的：发光材料是磷化铟或砷化镓体系的量子阱，镜子要么是芯片解理面，要么是刻在芯片里的光栅或多层反射镜。三种做法的区别是第 6 章的主题。激光器对温度敏感：温度升高，材料的能带间隙变小，发出的波长向长波漂移，大约每摄氏度漂 0.1 纳米3，所以不少高速模块在激光器旁边放一片半导体制冷片恒温，也有靠设计做到非制冷的产品4。

第四站：调制器怎么把数据写进光里

最简单的办法是直接调制：直接开关激光器的电流，电流大光就亮，电流小光就暗。速率低的时候这样够用；速率高了不行，因为改变电流会改变半导体里的载流子密度，进而改变折射率，让波长跟着抖动，这叫啁啾，会让脉冲在光纤里展宽2。所以高速模块用外调制：激光器只管恒定亮着，旁边另放一个器件负责"遮光"。

最常见的外调制器是电吸收调制器（EAM）：一段半导体波导，加反向电压时它的吸收边向长波移动，正好把激光器的波长吃掉，光就暗；不加电压时光通过，就亮。电压按数据变化，光强就按数据变化。这个效应叫量子限制斯塔克效应，第 6 章的 EML 就是把激光器和这样一段电吸收调制器长在同一块磷化铟芯片上3。硅光用的是另一种外调制器，原理留到第 6 章。

最后，透镜和耦合结构把光束收拢，对准一根纤芯只有 9 微米的单模光纤。这一步看似不起眼，速率越高对准要求越苛刻，第 5 章讲它为什么决定良率。

再深一层：物理细节与推导（读不懂可跳过，不影响主线）

均衡的数学。 信道可以近似为一个线性时不变系统，输出等于输入与信道冲激响应的卷积。前馈均衡（FFE）用一组抽头对当前和相邻符号加权求和，逼近信道响应的逆；判决反馈均衡（DFE）用已经判决出的前几个符号去减掉它们拖进当前符号的尾巴。更强的算法（最大似然序列检测）在整个序列上找最可能的比特组合。均衡做得越强，功耗越高，这是 DSP 功耗随速率暴涨的根源1。

为什么误码率是黄金指标。 接收端最终把每个符号判成 0 或 1，判错的比例叫误码率（BER）。以太网标准要求在前向纠错之前误码率不高于约 2.4×10⁻⁴，纠错后低于 10⁻¹³ 量级。DSP 的全部工作可以归结为一句话：把误码率压到标准以下，用尽量少的功耗。

受激辐射的三个条件。 粒子数反转（高能级电子比低能级多，靠注入电流实现）、谐振腔提供正反馈、增益大于损耗。半导体激光器在阈值电流以上才起振，阈值以下只是普通发光二极管。

量子限制斯塔克效应。 量子阱里的电子和空穴被限制在几纳米厚的层内，加电场后能带倾斜，有效带隙变小，吸收边向长波移动。EML 的设计核心是激光波长和调制段吸收边之间的"失谐量"：失谐小则消光比高但插损大，失谐大则相反，而且两者随温度漂移的速度不同（激光约 0.1 nm/°C，吸收边约 0.5 nm/°C），所以宽温工作是 EML 的难点3。

DSP 做哪两件事？
均衡：反向补偿信道对高频的衰减，把磨圆的边沿竖回来；重定时：恢复时钟，把符号重新对准节拍。
激光为什么是单一波长？
受激辐射产生的新光子与原光子波长相位相同；谐振腔只反复放大能形成驻波的那一种波长。
高速为什么不用直接调制？
开关电流会改变载流子密度和折射率，波长跟着抖动（啁啾），脉冲在光纤里展宽。所以激光器恒定亮着，用外调制器遮光。

光电探测器（PD，photodetector）是一个反向偏置的半导体二极管，材料的带隙比光子能量小：光子进来把一个电子从价带激发到导带，产生一对电子和空穴，被电场扫向两极，形成电流。每个光子最多产生一个电子，所以电流和光功率成正比1。跑了几百米之后到达的光只有几十到几百微瓦，产生的电流只有几十微安，后面的电路认不出来。

所以紧跟着要有一级跨阻放大器（TIA，Transimpedance Amplifier）：它的输入是电流、输出是电压，增益的单位是欧姆，一个几千欧的跨阻能把几十微安变成几十毫伏。TIA 决定了接收端的灵敏度：它自己的噪声电流有多小，就能分辨多弱的光信号，而噪声是一个不能用算法补回来的物理量2。放大后的信号进入 DSP，被重新采样、均衡，判决出每一位是 0 还是 1，交还给交换芯片。至此"电、光、电"一个来回走完。

耦合与封装：良率在哪里

发射端要把激光器发出的光对准光纤的芯，接收端要把光纤出来的光对准探测器的感光面。单模光纤的芯只有 9 微米，激光器的出光模场只有一两微米，两者之间要靠透镜放大匹配；对准误差每偏离一微米，耦合进去的光功率就掉一大截。速率越高，链路允许的光功率损失越少，对准容差越小。这道工序用主动对准设备做：一边通着光，一边挪动位置找耦合效率最大点，然后用胶或激光焊固定3。

一只模块有 8 条车道，每条都要对准；每道工序的良率相乘才是最终良率。立讯彭小伟的原话："光模块的制造，它的良率是累积的。比如有四个 90% 乘起来才是它的最终良率。"4四道 90% 是 66%，八道是 43%。良率高一个百分点，成本就低一截，这是模块厂真正的护城河，也是第 18 章耦合设备和测试设备的生意所在。

再深一层：物理细节与推导（读不懂可跳过，不影响主线）

探测器的响应度与带宽。 响应度等于每瓦光功率产生的电流，理论上限约 1 安每瓦（1,310 纳米）。带宽受载流子渡越时间和结电容限制，200G 每车道的探测器要做到 50 GHz 以上，就得把吸收层做薄、感光面做小，这又让对准更难。

TIA 的噪声。 输入参考噪声电流密度典型在每根号赫兹几皮安量级，带宽越宽积分噪声越大。灵敏度定义为达到目标误码率所需的最小平均光功率，每提高 3 dB 灵敏度，链路预算就多 3 dB，可以多传一段距离或多容忍一点耦合损失。

光功率预算。 发端出纤功率减去接收灵敏度就是这条链路能承受的总损耗，要分给光纤、连接器、耦合、老化余量。速率越高灵敏度越差，预算越紧，每一道耦合损失都更值钱，这就是"速率越高封装越重要"的定量含义。

发光的三条路线：VCSEL、EML、硅光

先打掉一个错误直觉

"硅光要是赢了，激光器厂就完了。"不对。硅是间接带隙材料，电子跃迁时要靠晶格振动帮忙，发光效率极低，做不了实用的激光器。硅光模块仍然要一颗磷化铟激光器，通常外置，也可以异质集成。变的是激光器的形态和颗数，不是有没有。

第 4 章说了激光器要两面镜子和一段发光材料，调制器要一段"遮光"结构。三条路线的差别，就是这几样东西各自放在哪、用什么材料做。

路线一：VCSEL，把镜子叠在上下

VCSEL（Vertical-Cavity Surface-Emitting Laser，垂直腔面发射激光器）把谐振腔竖着做：两面镜子不是芯片的两端，而是在衬底上一层一层长出来的多层反射镜，各几十对，每层四分之一波长厚，靠多层干涉把反射率做到 99% 以上。发光层夹在两镜之间，腔长只有一个波长量级。光从芯片表面垂直射出1。

好处是便宜和省电：一片晶圆上能同时做出成千上万颗，出光面就在表面，测试不用切片，光斑是圆的容易耦合；它用直接调制，不需要单独的调制器。代价是功率小、光谱不够纯，只能配多模光纤跑一百米以内；而且直接调制的带宽受限，传统的氧化孔径结构把带宽卡在约 27 GHz，也就是 100G 每车道的天花板，200G 要靠光刻孔径这类新结构2。所以 VCSEL 是 SR 短距模块的光源，也是手机人脸识别的光源。

路线二：EML，把激光段和调制段长在一条波导上

EML（Electro-absorption Modulated Laser，电吸收调制激光器）是横着做的：一条波导上串两段。前一段是分布反馈激光器（DFB）：不用两端的镜子，而是在波导下方刻一排周期性光栅，光栅对某一个波长产生分布式反射，只有这个波长能起振，所以光谱极纯、波长稳定。后一段是第 4 章讲的电吸收调制器，靠量子限制斯塔克效应遮光。两段长在同一块磷化铟（InP）芯片上，中间留一段电隔离区3。

它是单模中长距的黄金标准：光谱纯所以能跑两公里到十公里，调制段短所以电容小、带宽高，200G 每车道靠它最先量产。难点也在这里：两段要共用同一套量子阱材料，靠"激光波长与调制段吸收边的失谐量"这一个参数在宽温区里同时平衡消光比和输出功率；激光段要埋入式结构以耐高温，调制段要窄高台结构以压小电容，两种结构要在一片晶圆上做出来3。更根本的约束是材料：磷化铟晶圆主流还停在 3 英寸，硅是 12 英寸，产线少、设备交期长，第 13 章讲这个瓶颈。

路线三：硅光，把调制搬到硅片上，激光器外置

硅光（Silicon Photonics）反过来想：既然磷化铟难做，就只让它干一件事，发光。一颗只管恒定亮着的连续光激光器（CW laser）把光耦合进硅片，剩下的事全在硅片上做。硅的折射率高、硅与二氧化硅的折射率差大，能把光束缚在几百纳米宽的波导里拐弯；分束、合波、探测（用锗）都能做在同一片上，形成一颗光子集成电路。一颗激光器可以分给好几条车道用4。

硅光的调制器不能用电吸收，因为硅没有线性电光效应，只能靠载流子等离子色散：往波导里注入或抽走载流子，折射率跟着小幅变化，光的相位跟着变。相位变化本身看不见，所以要用马赫曾德结构把它变成明暗：光分成两臂，给一臂改相位，合并时同相相加就亮、反相相消就暗。或者用微环：一个小环靠近直波导，只有谐振波长的光会被抽进环里，加电压移动谐振波长，就等于开关这个波长的光4。载流子效应弱，所以马赫曾德要做得很长（毫米级），或者微环要做得很谐振、对温度极敏感；调制带宽也被载流子寿命卡住，华工正源罗传能在论坛上的口径是"硅光调制器带宽大约 70 GHz，做单波 400G 还要加补偿"5。

硅光走的是几十纳米的成熟 CMOS 制程，晶圆是 8 到 12 英寸，产能大、不依赖先进工艺。代价是多了一道把光从激光器导进硅片的耦合工序，角度歪一点损耗就大；调制器插损也比 EML 大。

三条路线的差别是"发光"和"调制"这两个动作放在哪、用什么材料做：VCSEL 竖着做腔、直接调制、便宜短距；EML 激光段和调制段长在一条磷化铟波导上、性能最好最难做；硅光把调制搬到硅片、激光器外置、成熟制程。硅不发光，所以硅光仍要买磷化铟激光器。

和翻译官对照

翻译官的嘴有三种：VCSEL 是小声说、只能隔近处听；EML 是一张天生会说话的嘴，又亮又清楚，但这样的嘴很少；硅光是把"发声"和"说话"拆开，用一个普通的声带（外置激光器）配一个精巧的口型（硅片上的调制器）。

投资视角

投资者看三条路线只需要盯一个问题：硅光占比上升的速度。硅光占比升，理论上缓解 EML 的缺口、抬高连续光激光器的需求；但份额下降不等于 EML 绝对量下降，总市场扩张时两者可以同时发生。每条路线上的公司、份额和现状，第 13、14、15 章逐个讲。

再深一层：物理细节与推导（读不懂可跳过，不影响主线）

分布式反射镜为什么要几十对。 单层界面的反射率只有百分之几，把高低折射率薄层交替叠起来、每层四分之一波长厚，各层反射的光同相叠加，反射率随对数指数上升，几十对可达 99.5% 以上。VCSEL 的腔增益只有几纳米厚的量子阱一次通过，所以镜子必须极高反射率，这是 VCSEL 外延生长厚度控制的极限活1。

为什么硅不发光。 硅的导带底和价带顶在动量空间里不在同一位置（间接带隙），电子跃迁发光必须同时有一个声子参与，概率极低，发光效率比磷化铟、砷化镓低几个数量级。所以硅光的光源要么外置，要么把磷化铟晶片键合到硅上（异质集成），Intel 的光 I/O 芯粒就是后者6。

载流子等离子色散。 自由载流子浓度变化 ΔN 引起折射率变化 Δn 约与 ΔN 成正比，1,550 纳米下每立方厘米 10¹⁷ 量级的载流子变化只带来 10⁻⁴ 量级的折射率变化。要让相位变 π，毫米级长度的波导才够，这就是马赫曾德调制器很长的原因；微环用谐振把相互作用长度"绕"出来，尺寸能缩到几十微米，但谐振波长随温度漂，要加热器锁定。

400G 每车道的争议。 Tower 与 Coherent 2026 年 3 月用量产级硅马赫曾德调制器做出了 400G 每车道的开眼图，Tower 的说法是"可以把硅再延长一代"；华工正源的口径是硅光 70 GHz 做 400G 要加补偿；薄膜铌酸锂器件已有 110 GHz 商用产品。三方都没错，争的是补偿的功耗和良率代价算谁的账57。第 15 章展开。

读完回答一下
VCSEL 的镜子和 EML 的镜子分别是什么？
VCSEL 是上下各几十对四分之一波长薄层的多层反射镜，垂直腔；EML 的激光段用波导下的周期性光栅做分布反馈，水平腔。
硅光为什么不能用电吸收调制，用什么？
硅没有线性电光效应，靠载流子等离子色散改折射率、改相位，再用马赫曾德或微环把相位变成明暗。
硅光赢了激光器厂会怎样？
硅不发光，硅光仍要磷化铟的连续光激光器；变的是激光器的形态与颗数。

芯片的嘴：SerDes

芯片内部是几百上千根并行的数据线，对外不能这么连，引脚不够。所以芯片边缘有一圈叫 SerDes（Serializer/Deserializer，串行器和解串器）的电路，把并行数据串成一条高速线发出去，收到时再拆开。USB、PCIe、以太网、NVLink 的底层都是它。SerDes 每条线的速度有一条经验曲线：10G、25G、56G、112G、224G，大约每三四年翻一倍，224G 从 2025 年起大规模商用1。这个节奏受模拟电路和封装的物理限制，很难加快。

而 AI 对带宽的需求是另一条曲线：模型规模和集群规模每半年到一年翻一倍，通信量跟着翻。两条线画在一起，就是一把张开的剪刀：

缺口怎么填：两条路，都指向同一个方向

一条路是多开车道：一条线不够就八条，八条不够就十六条。第 3 章讲过它的代价：交换芯片的口数不涨，零件随车道数线性增加，良率累积下降。所以这条路走不远。

另一条路是让光接管更多距离。每一代 SerDes 快一倍，铜能传清楚的距离砍半：每车道 100G 时铜能跑约两米，200G 约一米，400G 更短。第 2 章那个铜和光的交叉点每一代都往左挪一格。光迅科技蒋波在论坛上把这件事说透了："我不是要让光离芯片近，我的本质是要让电的链路越来越短。"2电走得越短，DSP 要补的码间干扰越少，功耗越低。所以光电转换点向芯片靠近，不是因为光想靠近，是因为电走不远。

有了这句话，后面的事都能推出来。光电转换点会从交换机面板搬到芯片旁边，这是第 19 章的可插拔、LPO、NPO、CPO；铜的厂商会用中继芯片把交叉点往右拽，这是第 17 章和第 20 章的有源铜缆；机柜之内 GPU 之间的互联也会开始用光，这是第 20 章的 Scale-up 光化。这些不是三件事，是一件事的三个表现。

本章核心

AI 对带宽的需求增速远快于 SerDes 的进步速度，所以铜能跑的距离一代比一代短，光电转换点被迫一步步靠近芯片。过去二十年从 10G 到 1.6T 是这句话的证据，LPO、NPO、CPO、光 I/O 是它的推论。

和翻译官对照

说话的人越说越快，铜线隔着能听清的距离越来越短，翻译官只好越搬越靠近说话的人：从大门口搬到走廊，再搬到办公桌旁。

PAM4 属于这一章。 在 SerDes 符号速率受限时，让每个符号携带 2 比特而不是 1 比特，是电这一侧榨最后一点性能的办法；代价是对噪声更敏感，DSP 要更强。400G 每车道之后用 PAM4 还是更高阶调制，行业尚未收敛。

Scale-up 与 Scale-out 的准确定义。 按协议域和拓扑划分，不按距离划分：Scale-up 是 GPU 之间的紧耦合直连域（NVLink 一类内存语义协议），Scale-out 是通过交换机的以太网或 InfiniBand 网络。常见部署是 Scale-up 在机柜内、Scale-out 在机柜间，但跨机柜的 NVLink 域也是 Scale-up。本书第 1 章用"机柜内、机柜间"只是常见例子4。

剪刀差的两条线分别是什么？缺口怎么填？

你现在在系统的这里
这一章看整条链上的钱：谁向谁买，谁能涨价。后面十章逐个环节拆。
读这一章前你已经懂的

先打掉一个错误直觉

"光模块股涨，是因为光模块厂技术领先。"更准确的说法是：模块厂是这条链上量最大、离需求最近、最先感知松紧的环节，所以弹性最大。技术上最难的两颗芯片在它的供应商手里。

钱从云厂商开始

链条的起点是云厂商的资本开支。2026 年前四大云厂商（Amazon、Alphabet、Microsoft、Meta）的资本开支指引合计约 7,250 亿美元，比 2025 年增七成多1。光模块只占其中很小一块：LightCounting 的口径是，卖给前五大云厂商的光器件占其资本开支的比例约 2.7%（2025）、3.1%（2026）、4.1%（2031）2。这个数字很重要，它解释了为什么云厂商在光模块上几乎不讲价也要拿到货：相对整个集群，光模块是最便宜的瓶颈。

读资本开支指引时要小心一件事：2026 年的上修里有相当一部分不是买了更多算力，而是内存和元件涨价。微软把日历年 1,900 亿美元里约 250 亿归因于元件涨价，亚马逊把 2,000 亿到 2,200 亿的上调归因于内存1。把这部分剔掉，才是真实的算力增量。

定价权怎么看

定价权是一个很简单的判据：缺货的时候，谁能涨价。这条链上，涨价的权力在两头。最上游的光芯片和电芯片，缺了没有替代：Lumentum 在 2026 年 5 月的电话会上说供需缺口"可能大于 30%"，8 月被问到有无改善时答"EML 大概没变化"3；博通 CEO 说激光器需求"远远超过供给"4。最下游的 GPU 是需求的源头。中间的模块厂在缺货时往往拿不到货，也不敢对客户涨太多，所以利润最薄；但它的量最大，景气时收入涨得最快。

毛利率把这件事写得很清楚：2026 年中，博通整体毛利率约 68%，Lumentum 非 GAAP 毛利率 50%，Coherent 40%，中际旭创模块业务 47%，光迅 26%5。同一条链上，越靠上游、越不可替代，毛利越厚。

路线中立与非中立

第 6 章讲了三条光源路线，第 19 章要讲四个封装选址。每一个分岔都有赢家和输家，但有些环节不管谁赢都要被买，这叫路线中立。激光器厂接近中立：EML 赢要买 EML，硅光赢要买连续光激光器；驱动器和放大器厂更中立：只要还有电光转换就必须有它们，一颗料号能通吃全部封装形态6。模块厂不中立：它在可插拔和 NPO 上是赢家，在纯 CPO 路线上是被绕过的一方。交换芯片厂也不中立：CPO 让它吃掉光引擎的价值。

中立不等于每 Tbps 赚一样的钱。同时卖 EML 和连续光激光器的公司，两者价格、良率、单模块颗数、缺口都不同：1.6T 硅光模块的激光器成本约 15 到 20 美元（4 颗 70 毫瓦连续光），1.6T EML 模块约 160 美元（8 颗 200G EML），差 8 到 10 倍7。

两个能问出来的数

判断松紧有两个不需要财务模型的数：交期（lead time，下单到交货要等几周）和稼动率（产线实际开工的比例）。交期拉长、稼动率满，就是紧。展台上问一句就有。还有一条领先关系值得记：LightCounting 明示，光模块销售转负领先云厂商资本开支转负约 6 个月2。模块厂"最先感知松紧"是有量化版本的。

本章核心

钱从云厂商流向 GPU 和交换机，再流向模块厂，再流向上游芯片。光器件只占云资本开支约 3%，所以云厂商不讲价。定价权在两头，弹性在中间。看松紧看交期和稼动率。

和翻译官对照

翻译公司（模块厂）接的单最多，但它的翻译的大脑和嘴都是从两家供应商那里买的。生意好的时候翻译公司收入涨得最快，缺人的时候先涨价的却是供应商。

投资视角

按石磊的"收益来源三分法"看：光芯片赚的是供给紧的定价权，电芯片赚的是双寡头的结构性利润，模块厂赚的是产业趋势的动量（量、稼动率、良率），设备厂赚的是扩产周期的先行动量，GPU 是需求源。每一种钱的脆弱点不一样，后面十章逐个说。

做什么

整机厂把上游的光芯片（EML、连续光激光器、硅光芯片）、电芯片（DSP 或线性驱动、放大器、微控制器）、光学件（透镜、光纤阵列）、高阶电路板和金属壳组装成一只符合标准外形的可插拔模块，交给交换机厂、服务器厂或云厂商自采。核心增值不在焊接，在耦合对准、校准、全温测试、良率与一致性。券商反复强调中际旭创的竞争力是新产品导入团队把研发和早期量产打通，以及"同一套设备兼容多种模块产线"的标准化工艺1。所以这是"规模加良率加供应链调度"的生意，不是"技术专利"的生意。

为什么难

物理瓶颈在上游，传导到整机厂：拿不到激光器就没有产能，Coherent 明说磷化铟产能是它的首要约束2。1.6T 当下被点名的另一个瓶颈是电路板：1.6T 模块用的高阶板年内涨价三成以上，供应商称即使大幅扩产，2027 年也只能满足需求的六到七成3。良率是时间换来的壁垒：券商测算中际旭创的产能与产量约为第二名的 1.5 倍，把"高产量下的良率经验"列为 1.6T 竞争有限的主因4。资本开支强度也高：券商预计旭创 2026 年资本开支增两倍半，产能从 2025 年 2,800 万只扩到 2028 年 1.2 亿只1。

受益：硅光渗透（光源成本降 8 到 10 倍，旭创硅光出货占比 50% 升向 86%，毛利率跟着抬）、Scale-up 光化（全新市场）、1.6T 到 3.2T 的单价台阶1。受损：CPO 若真快，模块组装的价值转移到交换芯片厂与光纤阵列、外置光源供应商（第 16、19 章）；LPO 省掉 DSP 会压低单价（净影响未查到量化）。整机厂不是路线中立的，所以旭创和新易盛都在往 NPO 和光引擎延伸；券商假设的 NPO 数量远大于 CPO（2027 年 3.2T NPO 360 万只对 CPO 10 万只）1。公司自己的说法要与第三方分开：Coherent 说 12 月季度开始有 CPO 收入，Lumentum 拿到外置光源（第 19 章）首单，器件厂两边都赚，被绕过的是整机厂。

最大的非技术风险是 FCC：路透 2026 年 8 月起报道 FCC 在起草提案，把中国制造的新型号光模块加入 Covered List，等于进口与销售禁令，但不要求拆除已装设备；"新型号"和"中国厂商"怎么定义未决。旭创的前瞻市盈率从 6 到 7 月的 21 倍压到 8 月的 15 倍；缓解论据是海外产能占比约 85%，风险敞口是美国市场约占其销售六成11。

看哪个数

  • 旭创和新易盛的"存货加应收"与经营现金流的背离幅度。背离收窄说明需求真实在出货，继续扩大说明在压渠道或产能空转。查半年报现金流量表首行与资产负债表。
  • Coherent 电话会里的两句话：磷化铟产出倍数，以及"订满到哪一年"。这是整条链上最硬的前瞻指标。
  • Fabrinet 的数通分部环比。代工厂走平而品牌厂暴涨，通常是缺料或换型。
  • FCC Covered List 的官方文本：关键是"新型号"定义与过渡期。
本章核心

整机厂是规模、良率、供应链调度的生意，量最大、利润最薄、最先感知松紧。中国占七席、六成收入。它在可插拔和 NPO 上是赢家，在纯 CPO 上被绕过，所以都在往光引擎延伸。最大的非技术风险是 FCC。

做什么

需求方把电力、土地、加速器和网络组装成 AI 集群，自用或出租。光模块在其中是"机柜之间的接线"，占比小但不可替代。英伟达既是 GPU 供应商，也是最大的网络供应商之一：Spectrum-X 以太网、InfiniBand 交换机和网卡都是它的，它定义 MGX 机柜参考设计，也就定义了每颗 GPU 配几个网口、每个口多快。博通 CEO 给的单位经济：1 GW 的 AI 集群约对应年收入 300 亿美元、年运营成本 100 亿美元1。

为什么"需求可见度"难

三个口径陷阱。第一，资本开支指引里有元件涨价：微软 1,900 亿美元里约 250 亿归因元件，亚马逊的上调归因内存2。第二，微软报的是"资本开支加融资租赁"的合计口径，还有日历年与财年之分，不写明口径会和流传的另一组数字打架。第三，券商预测极不稳定：一家券商在 2026 年 4 月到 9 月间把光模块金额预测一次上修 33% 到 115%3。把券商预测当真值，是这条链上最常见的错误。

先打掉一个错误直觉

"全球只有博通和 Marvell 两家能做 DSP。"头部份额确实集中在这两家，但 Credo 和 MaxLinear 都有在售的高速光 DSP，国内也有追赶者。准确说法是双寡头加第三第四家，份额百分比各口径冲突。

做什么

DSP 是电信号进模块的第一站和出模块的最后一站。正向做均衡与重定时，反向做重采样、均衡与判决，还带前向纠错和遥测：Credo 的规格书把"链路监控与诊断"列为卖点，十万卡集群里链路诊断能力本身就是采购理由1。论坛上光迅蒋波的一句话很准："DSP 把光和电的边界平滑了，脏活累活都给 DSP 干了；现在 NPO、CPO 没有 DSP 给我们兜底了。"2

为什么难

三重门槛。工艺：当前量产旗舰全是 3 纳米（博通 Sian3、Marvell Ara、Credo Bluebird），Marvell 说下一步往 2 纳米走3。模拟设计：每车道 224G 要在几十 GHz 上同时做模数转换、时钟恢复、多抽头均衡、非线性与反射抵消，Credo 把"接收机含非线性与反射抵消，改善良率"当卖点，反过来说明 DSP 的算法余量直接换模块厂的良率，这是它能收高价的根本1。功耗：一代先进节点只换来约两成的功耗下降（Sian3 相对 Sian2 对 1.6T 模块降"超过 20%"）4。资本与并购：Marvell 2021 年约 100 亿美元买下 Inphi，买的就是 PAM4 DSP 的 IP 与团队；Vol.75 的总结是"博通和 Marvell 通过并购形成双寡头"5。

硅光渗透：基本中立，EML 和硅光的可插拔模块都要 DSP。LPO：直接负面，是 DSP 唯一的生存威胁，均衡被拆给交换芯片、驱动器和放大器；但 Marvell 自己也卖 LPO 芯片组（2024-12-10 量产），两头对冲本身就是"不敢赌 LPO 不来"的证据9。第三方的反驳是 LPO 在 200G SerDes 上兼容性难；中国侧有强反例，一家云厂商称已在万卡集群规模落地 LPO，自测功耗降 29%、可靠性升约 70%（单一厂商自测）10。LRO（发射侧保留 DSP）：对 DSP 是减半不是清零，是当前 1.6T 的现实落点；Marvell 讲者在论坛上的口径是 800G 以全重定时为主，到 1.6T 全重定时与半重定时大约一半一半11。NPO 与 CPO：大多去掉 DSP，对可插拔 DSP 负面；Marvell 的应对是把自己重定义成光互连平台厂，收购 Celestial AI（前期对价 32.5 亿美元，或有对价最多 22.5 亿，总对价上限 55 亿，不是"对赌金额"）并把重心放在 NPO12。

看哪个数

  • 1.6T 里半重定时对全重定时的比例，锚是"大约一半一半"，决定 DSP 的单模块价值量。
  • MaxLinear 的光数据中心收入指引与 Rushmore 量产时点：第三家真正量产 200G 才意味着双寡头松动。
本章核心

DSP 的门槛是 3 纳米工艺加极限模拟设计加并购形成的 IP 集中，头部两家。它的唯一生存威胁是 LPO，现实落点是 LRO 减半；NPO 和 CPO 去掉它，DSP 厂的应对是把自己变成光互连平台。

你现在在系统的这里

做什么

驱动器把 DSP 输出的信号放大到激光器或调制器需要的摆幅；跨阻放大器把探测器的微弱电流变成电压交给 DSP。在 LPO 架构里它们还要兼任均衡器：没有 DSP 之后，信号再生与均衡被拆给交换芯片、驱动器和放大器三方分担，所以 LPO 的放大器被强调为"高线性度"1。一个容易搞错的边界：只要还有电光转换，就必须有驱动与放大，它们不会因为 DSP 消失或 CPO 到来而消失。

为什么难

模拟带宽：224G 每车道要求驱动器与放大器进到几十 GHz，MACOM 的代际是"每车道 227 Gbps"，Semtech 在 OFC 2026 演示到 448G，这是纯模拟指标，靠工艺节点堆不出来2。噪声：放大器的输入噪声电流直接决定灵敏度和可达距离，是一个不能用算法补回来的物理量3。产能：Semtech CEO 在 2026-08-25 电话会上说已把产能提升三到四倍，并且"已锁产能可能不足以支撑 FY28 下半年"，这是本次调研中唯一一条公司自己明确的产能不足表述4。被整合的风险是门槛的另一面：博通从 2023 年起把放大器和驱动器集成进 DSP，Sian3 内嵌激光驱动器，集成度越高，独立料号的插槽越少5。

先打掉一个错误直觉

做什么

EML 在一颗磷化铟芯片上把发光和写数据两件事做完，供 EML 路线的可插拔模块；连续光激光器只发光不调制，给硅光模块和 CPO 的光引擎供"电源"。一只 1.6T EML 模块用 8 颗 200G EML，一只 1.6T 硅光模块用 4 颗 70 毫瓦连续光激光器1。往上游两层：磷化铟衬底（晶圆）、磷化铟外延片（长出量子阱与光栅层），EML、连续光激光器和 200G 探测器全吃同一块衬底，这是整条链的物理公分母2。

为什么难

环节六：VCSEL

你现在在系统的这里
短距多模的光源，在 Scale-out 失势、在 Scale-up 等翻身。
读这一章前你已经懂的

  • SR 短距用多模光纤（第 3 章）

做什么与为什么难

VCSEL 是 SR 多模模块和有源光缆的光源；在 CPO 里它是"不需要外置光源、不需要微环锁定"的那条路线。它的门槛比 EML 低三处：不吃磷化铟而吃砷化镓，绕开了当前最紧的衬底；直接调制，省掉调制器、DSP 和多数场景下的制冷片；手机人脸识别给它留下了巨大的量产基座，Lumentum 称累计出货超过 100 亿颗发射单元1。难在两处：上下反射镜各几十对四分之一波长薄层，厚度偏差直接移动谐振波长，是外延厚度控制的极限活；传统氧化孔径把带宽卡在约 27 GHz，也就是 100G 每车道的天花板，Coherent 的突破是光刻孔径，把带宽推到约 45 GHz 够得上 200G2。多模光纤的带宽距离乘积也限制它只能跑一两百米，但 AI 机柜内 Scale-up 的实际需求只有 0.3 到 30 米，这个限制在新场景里基本不构成约束3。

现状与路线影响

没有单独的 VCSEL 财务披露。间接信号有两个：博通说 EML、连续光、VCSEL 与磷化铟工厂产能同比增三倍以上；IQE 提到砷化镓外延在为 AI 光互连做资格认证5。反向的实物证据更直接：Lumentum 的北卡厂是从砷化镓改造成磷化铟，2026 年的资本开支方向是把 VCSEL 产能转成 EML 和连续光产能，这是 VCSEL 在 Scale-out 战场失势的直接证据1。

Scale-up 是它的翻身机会。一篇 2026 年 1 月的预印本给出论证结构：训练阶段 Scale-up 占数据中心带宽八成以上；NVL72 一个机柜五千多根铜缆、总长 3.2 公里，空间已见底；铜在 200G 每车道下约 1 米、整链能效约 5 皮焦每比特；硅光引擎约 6.7 皮焦每比特；VCSEL 用"慢而宽"（更多通道、较低速率、不用 DSP 和纠错）被估到 1.5 皮焦每比特3。Coherent 2026 年 3 月的博客与此一致，称慢而宽的 VCSEL 共封装"有潜力接近端到端 1 皮焦每比特以下"，是厂商观点6。对立面是 MicroLED（Avicena），同一块市场。SR 多模在 Scale-out 里的份额趋势，方向上是共识（单模化），但具体百分比全部出自电商博客，不可引用。

环节七：硅光芯片与代工

做什么

硅光把除激光器之外的光学功能刻在一片硅晶圆上做成光子集成电路。分工是：设计方（模块厂自研或芯片公司）出版图与器件库，代工方（Tower、GlobalFoundries、台积电、三星）出工艺与产能，两者靠工艺设计套件绑定，换代工厂等于重做器件库。硅光的经济意义是省激光器：1.6T 硅光模块 4 颗 70 毫瓦连续光激光器约 15 到 20 美元，同速率 EML 方案 8 颗约 160 美元1。

为什么难

调制带宽是物理天花板：硅靠载流子改折射率，速度受载流子寿命限制，华工正源的口径是约 70 GHz、做单波 400G 要加补偿2。材料三难：薄膜铌酸锂性能最好但"还没有哪家代工厂能对外大批量发货"，磷化铟相对成熟，硅光供应链最强但性能最吃紧2。良率与生态：光子集成电路被要求在一两年内追平电集成电路几十年积累的自动化生产与测试生态，晶圆级测试时间要缩短五到六成3。激光器功率随封装形态跳档：外置光源出光超过 20 dBm 时端面容易被烧毁，对洁净度要求极高2。

路线之争的影响

硅光渗透显然受益，且受益不均：代工受益于所有硅光形态，自研硅光的模块厂受益于可插拔硅光，做 EML 的 Coherent 靠卖连续光激光器两头下注。LPO 中立偏不利：硅光调制器插损大于 EML，在线性链路里更吃光功率预算。NPO 与 CPO 强烈受益，因为几十个通道塞进一颗引擎几乎只能用硅光。Scale-up 光化是硅光代工最大的增量票，但券商与 SemiAnalysis 对时点分歧巨大，必须并列不选边。

  • Tower 每季度的硅光年化运行率与产能倍数：全链最早反映硅光订单真实落地的单一数字，代工要提前两三季备产能。
  • GlobalFoundries 通信与数据中心板块的同比：与 Tower 同时加速是真需求，一家加速一家掉是份额转移。
  • Coherent 是否改口对外供应磷化铟连续光激光器：改口意味着瓶颈解除。

本章核心

硅光靠省激光器赢得成本，靠成熟制程赢得产能；天花板是调制带宽。渗透率四个口径分母不同不可互换，代工端的数字更硬。硅光越多，磷化铟连续光激光器越紧，瓶颈没有消失，只是换了形态。

环节八：无源件，光纤阵列、连接器与外置光源

你现在在系统的这里
不耗电、不做转换，只负责把光准确送到该去的地方；CPO 让它从辅料变成主角。
读这一章前你已经懂的

做什么与为什么难

光纤阵列单元（FAU）把一排光纤端面按固定间距排在 V 型槽基板上，与光引擎上的波导阵列一根根对上，是光从芯片出来的第一道门；MT 插芯是多芯连接器里带精密孔阵的芯，MPO 是基于它的可插拔多芯连接器，MMC 是更小的新一代；外置光源模块把连续光激光器从引擎里搬到前面板可插拔盒里，坏了换模块不拆交换机。难在精度是微米与纳米级且公差累积：天孚自述的底座是"亚微米级高精密光耦合、纳米级模具设计"，波若威公开的光纤阵列间距公差正负 0.5 微米1。通道数每跳一档都是新工艺：CPO 用光纤阵列从 40 通道（3.2T，2026 年三季度）到 80 通道（6.4T，年内）到 100 通道（研发中）2。行业自己承认的结构性痛点是验证周期与方案迭代周期不匹配：圆桌上一位连接器厂代表说 NPO 项目"没有一个是完全一样的"，连接器验证以半年为单位，方案落地以月计3。

插座标准之争：LGA 对扣板

NPO 的光引擎靠插座装在交换芯片旁的板上，插座是什么形态还没定。触点阵列（LGA）：电路板侧与光引擎侧都是触点，不需要回流焊，规范一旦定下各家容易互联互通，连接器公司也有优化自家界面的积极性。扣板（Mezzanine）：上下可拆，但需要回流焊。圆桌上连接器厂代表的判断很尖锐：技术早就不是瓶颈，"20G 已经量产快两年了"；没有商业授权只靠标准界定尺寸，模块厂和系统厂是两个不同的客人，最后很可能配不上；而商业授权意味着"一家设计、多家生产"，会压制创新3。华工正源的痛点是"最难定的就是插座，每一家给的方案都不一样，每一家我要做一个方案"8。三方摆一起：模块厂要插座只有一种，连接器厂要规范定尺寸但留创新空间，标准组织要"管住交互层、放开实现层"。结局决定连接器环节是多家竞争的标准件生意还是一家授权多家代工的许可生意，毛利率天差地别。

路线之争的影响与看哪个数

硅光渗透中性偏受益（光纤阵列跟着硅光走，通道更密）；NPO 受益且比 CPO 更受益（保留插拔界面又多了引擎级需求）；CPO 强受益但集中度高，门槛由 NVIDIA 和博通的认证决定；Scale-up 光化是最大的潜在增量，三家云厂商给的时间点差两年（阿里猜 2028，腾讯说明年到后年）3。要警惕的竞争：中际旭创 2027 到 2028 年把光纤阵列和外置光源列为自己的新产品线，天孚最大的客户群正在往它的主业里走2。

  • 天孚半年报"分产品"表里无源光器件的收入增速与毛利率，同时看有源那一行。
  • 光纤阵列通道数与单价的同步推进（40 到 80 到 100 通道；约 51 到 77 到 91 美元）。
  • Corning 企业业务的季度同比与资本开支。
  • 展台问：80 通道的良率比 40 通道差多少，哪道工序限制；你们押触点阵列还是扣板，客户两种都要你开几套模。
本章核心

无源件不耗电不转换，但 CPO 和 NPO 让光纤阵列、插芯、外置光源从辅料变成决定能否量产的结构件。天孚 2026 年上半年无源件增 77%、毛利率 72%，是这件事在财报上的落痕。插座标准之争决定连接器是标准件生意还是许可生意。

环节九：交换芯片与系统厂，含光交换、相干与铜的对手

读这一章前你已经懂的

做什么

交换芯片一侧接几百上千条 SerDes，另一侧是决定每个报文往哪个口走的交换结构，输入输出都是电；面板上那排光模块笼子是把电交给光模块。所以交换芯片的每车道速率直接决定面板上能插什么模块。系统厂把芯片做成整机：电路板、电源、散热（1.6T 代际已普遍液冷）、网络操作系统、认证；分品牌机（Arista、Cisco）和白牌（Celestica、Accton、Quanta），区别是谁拥有操作系统和客户关系。光交换机（OCS）是另一类东西：不看报文、不做转发决策，用微镜或液晶把一根光纤的光切到另一根，是自动配线架。相干管楼与楼、城与城之间，用光的相位和幅度同时载信息。铜是这一环的对手：铜够得到的短距链路不需要光模块。

为什么难

SerDes 是模拟设计，不靠制程堆：博通 Tomahawk 6 单芯片 102.4T，给两种配置，1,024 条 100G 或 512 条 200G，让 200G 的眼图在封装和电路板上活下来是这一环最硬的门槛1。CPO 把封装难度搬进交换芯片：TH6-Davisson 在同一封装里放 16 颗 6.4T 光引擎，任何一颗坏，整个封装件报废2。光交换的难点不在开关在光学余量：谷歌 Palomar 用三维微镜做到 136 乘 136 无阻塞、最大插损 2 dB、整机 108 瓦，把 2 dB 做到量产一致且十年不漂是真门槛3。系统厂的门槛是规模和认证：白牌里 Accton 加 Celestica 约占九成4。

现状与 CPO 交换机的可用时间

铜的对手，以及一个改叙事的发现

每车道 224G 下无源铜约 1 到 2 米，带中继芯片的有源铜缆在 112G 代际覆盖 0.5 到 7 米，升到 200G 约 5 米（后者只有二手）7。NVL72 每柜五千多根铜缆，供应商归属是渠道推断；Rubin 一代改为中置背板加盲插连接器，会改变这条需求的性质8。Credo 已经不是纯有源铜缆标的：FY27Q1 收入 4.79 亿美元、增 115%，管理层指引 FY27 光 DSP、硅光芯片、ZeroFlap 光模块各超 1 亿美元、光学总收入超 6 亿美元，CEO 原话"有源铜缆继续增长，光学增长更快"；前四大客户合计 84%9。用"SerDes 升级则铜缩短则 Credo 受损"这条单线会漏掉公司主动换赛道。博通是两头下注的典型：TH6 发布稿宣传"200G SerDes 提供业界最长的无源铜可达距离"，TH6-Davisson 宣传 CPO 降功耗七成12。

路线之争的影响与看哪个数

交换芯片厂不中立：CPO 让它吃掉光引擎的价值，可插拔让它只卖芯片。系统厂相对中立：模块在面板还是封装里，整机都要它做；白牌在 NPO 下受益更明确。铜缆与中继芯片厂随 SerDes 代际受损，这是物理性侵蚀，但受损的是"铜"这个产品，不一定是卖铜的公司。光交换与 CPO 不是替代关系，是网络的不同层面，可以并存。

  • TH6-Davisson 从早期客户到正式发布的时间点，以及第四代 400G 平台的宣布时点：这是"CPO 到底是 2026 还是 2029"最早能被证伪的地方。
  • Arista 的 AI 网络年度指引与 Etherlink 客户数；Celestica 的分部收入与 800G、1.6T 的提及方式。
  • Credo 的"光学收入对有源铜缆收入"增速差与 10-Q 客户集中度。
  • 光交换：Coherent 与 Lumentum 电话会里的客户数与月产能；展台问"这一代 300 乘 300 还是 512 乘 512，插损预算多少，切一次光路多少毫秒"。
本章核心

交换芯片决定每车道速率，是 CPO 的主导者也是铜的推销者；系统厂靠规模与操作系统；光交换是配线架不是替代品；铜的对手在被物理侵蚀的同时主动换赛道。

读完回答一下
交换芯片的每车道速率为什么决定模块代际？
面板上的模块要匹配芯片 SerDes 的速率，芯片 200G 才谈得上 1.6T 模块。
光交换机和普通交换机的根本区别？
不做光电转换，用镜子或液晶切光路；不看报文，功耗与附加延迟很低，有毫秒级切换时间。
Credo 的叙事为什么变了？
光学收入指引超 6 亿美元、增速快于有源铜缆，它在主动从铜换到光。

先打掉一个错误直觉

"CPO 多两道测试，测试设备销量就翻倍。"不对。设备需求取决于件次、单件时间、并行站数和稼动率四个变量，Teradyne 自己的 10-K 把"并行测试可能缩小测试市场"列为风险。插入点增加不等于设备销量线性增加。

做什么与为什么难

耦合封装设备把激光器裸片、硅光芯片、光纤阵列以亚微米精度贴到一起并固化：高精度贴片机、主动对准台（一边通光一边挪位置找最大耦合效率）、激光焊接。测试分三到四个插入点：晶圆级电光探测（切片前挑出合格裸片）、晶圆级老化（筛早期失效）、光引擎级、模组级。封测代工把这两件事当服务卖：日月光与矽品、Amkor、台积电 COUPE。难在精度是亚微米（ASMPT 的贴装精度标称正负 0.2 微米，这个量级上设备热膨胀、胶水收缩、基板平整度都会吃掉余量）1；良率累积（四道 90% 是 66%）；硅光晶圆要正面打电、另一面耦光，Teradyne 与 ficonTEC 2025-03-31 发布业界首个双面晶圆探测系统2；整个光子生态的自动化成熟度落后电芯片几十年，却被要求一两年内追上3。

现状（2026 年中）

FormFactor 2Q26 收入 2.58 亿美元创纪录、增 32%，Systems 分部增长"主要由 Triton 驱动"，CPO 收入口径 2026 年约 2,000 万美元，以季度收入为分母，光子测试今天还很小，但"今天小"不等于增速低5。Aehr FY26Q4 收入 1,880 万美元、季度订单 6,070 万创纪录，FY27 指引 1.30 到 1.50 亿美元、增 160% 到 200%；但"AI 处理器占 71%"这类应用占比新闻稿里没有，三个流传数字互不相同，必须用 10-K 复核6。ficonTEC：罗博特科并表的业绩承诺是 2025 到 2027 累计扣非净利不低于 5,814.5 万欧元；公司口径"未来一年出货台数超过过去 25 年总量的一半"，流传的"18 个月再出 1,000 台"上一轮审核已标注计划、订单、出货三者必须区分7。Teradyne 整体分部里光子只是小块，不能拿 Photon 100 给整家公司定价2。

路线之争的影响：先写三条被纠正过的推理

纠正一，插入点增加不等于设备销量线性增加。 设备需求约等于各站件次乘单件时间除以并行站数、年可用小时、稼动率之和。透明算例：件次增 50%、单件时间增 20%，但并行翻倍、稼动率从 60% 升到 80%，所需设备反而减少 32.5%；并行与稼动率不变则增 80%。同一套需求叙事可以推出相反的设备销量方向8。纠正二，良率提升不必然降低测试需求。 合格品需求翻倍、良率从 80% 升到 95%，投入仍增约 68%。纠正三，CPO 的晶圆级老化不是所有架构都必选。 NVIDIA 用可现场更换的外置光源，激光器有老化风险不能直接推出每颗硅光芯片都需要相同的老化工序9。

在此基础上：NPO 对设备是温和增量，立讯彭小伟说 NPO 的耦合"沿用原来可插拔光模块的耦合设备，工艺可以迁移"，但同一场也说 NPO 要用先进封装、传统与先进封装厂都在抢10；CPO 是新增插入点，但要经过纠正一的折算；高精度贴装设备相对中立（三条路都要贴），晶圆级老化最不中立（随激光架构分叉），晶圆级探测介于两者之间（硅光渗透上升就受益）。Aehr 的归因边界：AI 处理器烧机、碳化硅、硅光是三个独立需求变量，把它的指引当 CPO 验证跨越了公司从未披露的应用占比。

本章核心

耦合与测试设备是把良率做出来的人。它的需求不随插入点线性增长，要看件次、单件时间、并行和稼动率。贴装设备中立，晶圆级老化最不中立，晶圆级探测跟硅光渗透走。

先打掉一个错误直觉

"CPO 一出来，可插拔光模块就没了。"第 1 章说过光模块插在两种设备上：交换机和网卡。CPO 改的是交换机这一侧，网卡那一侧的模块还在；英伟达自己的新闻稿写的是 Spectrum-6"同时支持可插拔与共封装光学"。

所有方案本质上是同一道选址题：翻译官站在离交换芯片多近的地方。离得远，好换好修但电走得长、码间干扰重、DSP 补偿多、最耗电；离得近，电走得短最省电，但光引擎坏了更换的粒度变大。

可插拔
站在前面板。坏了拔掉换一只。电从芯片到面板走几十厘米，全靠 DSP 整形。
→
LPO / LRO
还在前面板，但拿掉全部或接收侧的 DSP，靠交换芯片自己的 SerDes 把话说清楚。省电省钱，短距。
→
NPO
搬到交换芯片旁几厘米的板上，用插座连接，开盖能换。
→
CPO
光引擎和交换芯片封装在同一块基板上，电只走一两厘米。最省电，更换粒度最大。

CPO 的一个关键设计：既然激光器最怕热、最容易坏，就不封进芯片，而是拿到面板上做成可插拔的外置光源模块，用保偏光纤把光送进去。这也是激光器厂在 CPO 时代依然有生意、且单颗功率和单价上移的原因（第 13 章）。但外置不是 CPO 的物理必然，Intel 的光 I/O 芯粒把激光集成在片上。

2026 年 9 月站在哪

博通的 CPO 交换机 TH6-Davisson 2025 年 10 月宣布出货，是它的第三代 CPO；英伟达的 Quantum-X Photonics 2026 年 6 月在 Lambda 的万卡集群投入生产，Spectrum-X Photonics 官网写 2026 下半年可用，英伟达在 LightCounting 7 月的会上称 CPO 已进入 Scale-out 量产1。但在光博会的论坛上，中国的云厂商和模块厂几乎一致把重心放在 NPO：立讯彭小伟的原话是"NPO 本质是一个可插拔产业链的延续"，耦合沿用原设备、工艺可迁移、运维仍可插拔，"完全避免了 CPO 一坏了要整体返修的问题"，但"没有自己的光、没有先进封装，要跟人合作"；百度、阿里、腾讯的判断都是 NPO 会比 CPO 先落地，因为 NPO 是开放生态、多家竞价，CPO 意味着被交换芯片厂绑定2。Marvell 的重心也放在 NPO3。

光迅科技蒋波把这场迁移说成"责任主体的迁移"：可插拔时代模块厂管光学和良率，系统厂管电路板和散热；到了 NPO 和 CPO，系统厂要自己管全部环节。谁管，谁就有定价权4。LPO 的现实落点：100G 每车道的 LPO 已在一家云厂商的万卡集群规模落地；200G 每车道上第三方判断 LRO 更现实，Marvell 讲者的口径是 1.6T 全重定时与半重定时大约一半一半（第 11 章）。

再深一层：功耗和可靠性的账

再深一层：物理细节与推导（读不懂可跳过，不影响主线）

英伟达的功耗账。 同一个 1.6T 端口：传统可插拔约 30 瓦（DSP 约 20 瓦加激光约 10 瓦），CPO 约 9 瓦（光引擎约 7 瓦加外置激光约 2 瓦）。官方倍数改过口径：2025 年 3 月说能效提升 3.5 倍，2026 年官网说 5 倍；激光器数量减少约 4 倍。引用要带年份5。

第三方账。 SemiAnalysis 估算 800G 可插拔约 16 到 17 瓦，英伟达 CPO 折合每 800G 约 4 到 5 瓦；Meta 实测博通 CPO 交换机每 800G 从 15 瓦降到 5.4 瓦。切到 CPO 后光模块成本降约 86%，但交换机本体成本涨约 81%，三层网络整集群成本只省约 3%。可靠性：可插拔模块返修中约 80% 是"没查出问题"（付费文章，需自行复核）6。Lambda 的部署口径：常规交换机约 7.0 千瓦、CPO 交换机 3.95 千瓦1。

光迅现场的"封装革命"一页 把三级台阶各自先撞的墙列出来：前面板可插拔先撞面板密度、散热、走线损耗；近封装先撞插座、光纤阵列、冷板维护；共封装先撞封装良率、热、测试与维护。结论一句："光电转换的位置不是路线之争，而是在电路径、密度、能耗与维护之间选择最优边界。"

本章核心

四个选址是同一道题：光电转换点建在离芯片多近的地方。这是一道"哪条成本曲线先弯下去"的经济题，不是"哪条技术更先进"的技术题。答案取决于电价、良率和可维护性，这些都是能在展台上问出来的数。2026 年的现实是北美 CPO 已出货、中国重心在 NPO、LPO 在 100G 落地而 200G 走 LRO。

和翻译官对照

CPO 为什么要把激光器拿到外面？

为什么中国厂商更倾向 NPO？
NPO 延续可插拔产业链，开放生态多家竞价；CPO 要被交换芯片厂绑定。

先打掉一个错误直觉

"投资光通信就是判断哪条技术路线更先进。"每个分岔的胜负都由成本曲线决定，成本曲线的拐点表现为几个能观察的物理量。盯数，不盯口号。

第 7 章那句话推出了三件事，它们就是今天这个行业最大的三个分岔。每个分岔都不需要预测，只需要知道看哪个数、目前的读数是多少。

分岔一：硅光占比升多快

硅光占比升，理论上缓解 EML 的缺口、抬高连续光激光器的需求；但份额下降不等于 EML 绝对量下降。看：硅光在 800G、1.6T 出货里的占比；EML 与连续光激光器的交期与缺口。目前读数：四个口径并列，LightCounting 称 2026 年硅光调制器收发器销售额首次过半，券商按速率档 60/80/80%，按总数量只有 10%，中际旭创自述 38% 升向 73%，分母不同不可互换（第 15 章）；磷化铟需求超供给约三成，Lumentum 8 月说"EML 大概没变化"（第 13 章）。代工端的数字更硬：Tower 硅光年化超 6.8 亿美元、2027 年签约 13 亿1。

分岔二：CPO 何时量产替代交换机侧可插拔

CPO 交换机全面量产，是交换机侧可插拔份额开始被替代的临界事件，不是可插拔利润消失；网卡侧的模块不受影响。分层替代的示意模型：两层网络里只换脊层，可插拔壳数减约 25%，只换叶层减约 50%，全换 75%2。看：CPO 交换机的良率与出货量；模块厂有没有拿到光引擎和外置光源的订单；博通第四代 400G 平台的宣布时点。目前读数与分歧：券商称 CPO 占 800G 以上出货 1%/6%/9%（2026 到 2028），SemiAnalysis 称 CPO 要到 2029 年，比街上预期晚两年；TrendForce 称 2030 年渗透率或达 35%，LightCounting 基准只假设 10% 到 15% 的 Scale-up 互连在 2030 到 2031 年迁移到 NPO 或 CPO，Yole 把大规模部署定在 2028 到 20303。这是最值得做成"分歧监控项"的一条，不要替读者裁决。

分岔三：铜还能守几米

有源铜缆（AEC）是在铜缆里加一颗中继芯片，把信号在半路整形一次，让铜从一两米撑到五到七米，机柜内和相邻机柜可以继续用铜，它直接决定第 2 章那个交叉点往哪边挪。交叉点的另一边也在动：英伟达公布了把多个机柜连成一个 NVLink 域的方案，跨机柜那段用光；谷歌的 TPU 集群用光交换把上百个机柜连成一个域。机柜内 GPU 互联开始用光，是一块新增的光市场，要和交换机侧的替代分开算。看：下一代 SerDes 速率下有源铜缆的可用距离；机柜内 GPU 互联有没有开始用光；Credo 光学收入对有源铜缆收入的增速差。目前读数：224G 下无源铜约 1 到 2 米、有源约 5 米（后者二手）；Marvell 与立讯口径 400G 每车道"势必导入光"；三家云厂商对国内 Scale-up 光化的时间点差两年（第 16 章）；英伟达 NVL576 量产日期官方未给；Credo 指引 FY27 光学收入超 6 亿美元（第 17 章）。

两条旁支

光交换机（OCS）不做光电转换，用微镜或液晶直接切光路，不看内容所以不能做复杂路由，但功耗和附加延迟都很低（仍有控制功耗和毫秒级切换时间），速率无关；谷歌用它去掉了一层电交换机，其余各层的光模块还在，OCS 与 CPO 不是替代关系。空芯光纤把玻璃芯换成空气，延迟低三成、损耗更低，目前很贵，早期概念。两者的玩家见第 17 章。

把三个分岔接回那一句话

三个分岔看起来是三件事，其实是第 7 章那句话的三个表现。硅光占比是"发光和调制分不分开"，CPO 是"转换点搬多近"，铜的反击是"交叉点往哪边挪"。都是电走不远、光被迫接管之后，产业链在不同位置的应对。谁赢，取决于谁的成本曲线先弯下去。

词汇表

光模块optical transceiver
插在交换机或网卡口上、把电变光和把光变电的可插拔盒子，收发一体。
光引擎optical engine
光模块去掉外壳和电口后的核心光电部分，NPO 和 CPO 里用的就是它。
网卡 NICNetwork Interface Card
GPU 或服务器对外打电话的口。
交换机switch
总机，读报文地址把数据转到正确出口。柜顶第一级叫叶，更上一级叫脊。
全归约all-reduce
数据并行训练里每步把所有 GPU 的梯度求和平均再发回的操作，通信量与参数量同量级。
趋肤效应skin effect
高频交变电流被自身磁场感应的涡流推向导线表面，有效截面缩小，电阻随频率平方根上升。
介质损耗dielectric loss
绝缘材料在高频电场里反复极化生热，随频率线性上升。
码间干扰inter-symbol interference
高频分量衰减多，方波边沿磨圆，相邻比特重叠，接收端分不清 0 和 1。
全反射total internal reflection
光从高折射率介质射向低折射率介质、入射角大于临界角时全部反射，光纤靠它把光困在纤芯里。
车道 lanelane
模块里并排的一路信号。800G 是 8 条 100G。
SR / DR / FR / LR / ZR距离等级
约 100 米 / 500 米 / 2 公里 / 10 公里 / 80 公里以上。SR 用多模光纤，其余单模。
OSFP / QSFP-DD外壳规格
模块的机械尺寸标准。1.6T 基本用 OSFP。
DSP / ODSPDigital Signal Processor
模块的大脑：均衡（反向补偿信道）与重定时（恢复时钟），最耗电，头部集中在两家。
均衡equalization
用前后几个符号的加权和抵消码间干扰，把磨圆的边沿竖回来。
驱动器driver
把 DSP 的微弱信号放大到激光器或调制器需要的摆幅，与光器件配对设计。
受激辐射stimulated emission
高能级电子被经过的光子触发跳回低能级，放出一个波长相位方向完全相同的新光子。
谐振腔resonant cavity
两面镜子之间让光反复放大，只有能形成驻波的波长被选出。
调制器modulator
把连续的光按数据变成明暗。电吸收调制器靠加电压吸光，硅光靠改相位。
光电探测器 PDphotodetector
反向偏置的半导体二极管，光子进来激发电子空穴对，形成与光功率成正比的电流。
跨阻放大器 TIATransimpedance Amplifier
把探测器的微弱电流变成电压，它的噪声决定接收灵敏度。
VCSEL垂直腔面发射激光器
上下各几十对四分之一波长薄层做镜子，腔竖着，光从表面射出；砷化镓；直接调制；多模短距。
EML电吸收调制激光器
一条磷化铟波导上串一段分布反馈激光器和一段电吸收调制器；单模中长距，最难做。
DFB分布反馈激光器
波导下方刻周期性光栅做分布式反射，只让一种波长起振，光谱极纯。
磷化铟 InPindium phosphide
做 EML、连续光激光器和高速探测器的化合物半导体，晶圆主流 3 英寸，产能紧。
硅光Silicon Photonics
把调制器、波导、探测器做在硅片上，用成熟 CMOS 制程；硅不发光，激光器外置或异质集成。
马赫曾德调制器Mach-Zehnder modulator
光分两臂，改一臂相位，合并时同相亮反相暗；硅光常用，毫米级长。
微环调制器micro-ring modulator
小环靠近直波导，加电压移动谐振波长来开关这个波长的光；尺寸小但对温度敏感。
连续光激光器 CWContinuous Wave laser
只管亮不管闪，给硅光和 CPO 供光；功率从 70 毫瓦到 400 毫瓦分档。
薄膜铌酸锂 TFLNthin-film lithium niobate
有线性电光效应的材料，调制带宽超过 100 GHz，供应链待验证。
PAM4四电平脉冲幅度调制
一个符号传 2 比特而不是 1 比特，同样符号速率跑出两倍数据，代价是对噪声更敏感。
SerDes串行器 / 解串器
芯片边缘把并行数据串成一条高速线的电路，单线速度约每三四年翻一倍。
可插拔pluggable
光模块插在设备面板上，坏了拔掉换一只。现状主流。
LPO / LRO线性直驱 / 线性接收
去掉全部 / 接收侧 DSP 的可插拔模块，均衡拆给交换芯片、驱动器和放大器。
NPO近封装光学
光引擎搬到交换芯片旁几厘米的板上，用插座连接，开盖能换；延续可插拔产业链。
CPO共封装光学
光引擎和交换芯片封装在同一块基板上，最省电，更换粒度最大。
外置光源 ELSExternal Laser Source
CPO 时代把连续光激光器做成前面板可插拔的盒子，用保偏光纤送光进去。
光纤阵列单元 FAUFiber Array Unit
一排光纤按固定间距排在 V 槽基板上，与光引擎的波导阵列对准，CPO 的第一道门。
MT 插芯 / MPO / MMC多芯连接器
MT 是带精密孔阵的芯，MPO 是基于它的可插拔多芯连接器，MMC 是更小的新一代。
有源铜缆 AECActive Electrical Cable
铜缆里加中继芯片，把铜从一两米撑到五到七米。
光交换机 OCSOptical Circuit Switch
不做光电转换，用微镜或液晶直接切光路；功耗与附加延迟很低，有毫秒级切换时间。
相干coherent
用光的幅度和相位同时载信息，用于几十到几千公里的数据中心互联。
Scale-up / Scale-out纵向 / 横向扩展
按协议域划分：GPU 之间的紧耦合直连域 / 通过交换机扩展的网。常见部署在机柜内 / 机柜间，但跨机柜的 NVLink 域也是 Scale-up。
累积良率cumulative yield
各工序良率相乘；四道 90% 只剩 66%。
定价权pricing power
缺货时谁能涨价。
交期lead time
下单到交货的周数，供应链松紧最直接的物理量。
稼动率utilization
